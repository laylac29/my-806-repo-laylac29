Introduction

This data identifies the most visited restoration sites and could help predict what sites will be most used and the types of visitors expected to use each site.

##Data This data is from EDI Data Repository: Sacramento-San Joaquin Delta Socioecological Monitoring. It details locations and visitors to sites.

#creates new variable where all names have the same format
delta_visits <- delta_visits_raw %>% 
    janitor::clean_names()
#makes data tidier with long format
visits_long <- delta_visits %>%
  pivot_longer(cols = c(sm_boat, med_boat, lrg_boat, bank_angler, scientist, cars),
                 names_to = "visitor_type",
                 values_to = "quantity") %>%
    rename(restore_loc = eco_restore_approximate_location) %>% 
    select(-notes)

# ℹ 1 more variable: quantity <dbl>
daily_visits_loc <- visits_long %>% 
    group_by(restore_loc, date, visitor_type) %>% # splits dataset into 3 groups
    summarise(daily_visits = sum(quantity)) #adds all quanities and creates new variable
#re orders the categories
daily_visits_totals <- daily_visits_loc %>% 
    group_by(restore_loc) %>% #all of the sam elcoation are grouped together
    mutate(n = sum(daily_visits)) %>% #adds daily visits for each location
    ungroup() %>%
    mutate(restore_loc = fct_reorder(restore_loc, n)) #reorders based on total visits

locations <- visits_long %>% 
    distinct(restore_loc, .keep_all = TRUE) %>% #uses rows from restore_loc
    select(restore_loc, latitude, longitude) #keeps columns restore_loc, latitude, longitude
leaflet(locations) %>%
    addTiles() %>% #adds tiles to map
    addMarkers( #adds markers for locations with pop up with location from restore_loc
        lng = ~ longitude,
        lat = ~ latitude,
        popup = ~ restore_loc
    )

Discussion

The bar plot shows each location’s total number of visitors in descending order and also splits the bars up to show how many of the total visitors for each location belong to different groups of types of visitors. Med boats appeared to be the most abundant visitor type across all locations.
